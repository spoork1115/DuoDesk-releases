# DuoDesk 배포

**DuoDesk** — 직장인을 위한 2창 파일 탐색기 (Windows 10/11 x64).

이 저장소는 실행 파일 배포 전용입니다. [최신 릴리스](../../releases/latest)에서 `DuoDesk-win-x64.zip`을 받아 압축을 풀면 `DuoDesk` 폴더가 나옵니다. 그 안의 `DuoDesk.exe`를 실행하세요. 설치·관리자 권한이 필요 없으며 설정은 exe 옆 `data\` 폴더에 저장됩니다.

설치된 앱은 이 저장소의 최신 릴리스(`version.json`)를 확인해 자동으로 업데이트합니다. (`DuoDesk-update.zip`은 자동 업데이트용입니다.)
